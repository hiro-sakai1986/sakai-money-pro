# サカイ家 MONEY Pro 8.0 Alpha

7.0 第三弾Dの全データを引き継ぎながら、8.0用の新しい画面デザインと保存領域へ移行した最初の開発版です。

## 8.0 Alphaで変更したこと
- iPhoneアプリ風の新しいホームデザイン
- 8.0専用ストレージキー（7.0 第三弾Dから自動移行）
- ライフプランタブの名称整理
- 日付・端末内保存ステータス表示
- PWAキャッシュ更新

既存の家計・投資・住宅ローン・教育資金・目的別積立・ライフイベント機能はそのまま利用できます。


## 8.0 Alpha データ復旧修正版

旧バージョンで実際に使われていた保存名も検索し、8.0が先に空データを保存した後でも、
同じブラウザー内に残っている旧データを自動で引き継ぐように修正しました。


## 8.0 Beta 家計画面

- 月別の収入・支出・収支・貯蓄率を表示
- 月ごとの支出予算と予算オーバー判定
- よく使うカテゴリから簡単入力
- 家計記録の編集・削除
- 6か月の収入・支出グラフ
- 支出カテゴリ別の内訳と割合
- 8.0 Alphaの保存データをそのまま引き継ぐため、保存キーは維持


## 8.0 Beta 第2弾 投資画面

- 本人・夫・家族合計の投資ダッシュボード
- 投資評価額・元本・損益率・年間配当・毎月積立を一画面に集約
- 資産種類別と口座別の構成比
- 集中度、価格未入力、積立額、配当月未入力の端末内チェック
- 保有資産・積立・ランキング・配当をタブで切替
- 保有商品の構成比バー、NISA口座チップ、入力不足表示
- 既存の8.0 Betaデータをそのまま維持（保存キー変更なし）


## 自動保存強化修正版

- 保存名を今後の更新でも固定
- 通常保存に加えて予備保存（IndexedDB）を追加
- アプリを閉じる・バックグラウンドへ移す直前にも保存
- 通常保存が消えた場合は予備保存から自動復旧
- GitHub Pages更新後も同じ保存領域を継続使用


## 配当カレンダー修正版

- 「本人」「ヒロ」「妻」「自分」「私」を本人名義として統一
- 「夫」「旦那」「主人」を夫名義として統一
- 旧データの名義表記が違っていても配当カレンダーに表示
- 配当月は `6,12` のほか、`6月・12月`、`6／12`、全角数字にも対応
- 同じ月が重複入力されても一度だけ計算
- 保存領域と既存データはそのまま継続


## 8.0 Beta 第3弾 投資枠整理版
- 「買い方（毎月積立／一括購入）」と「口座区分（NISAつみたて／NISA成長／特定など）」を分離
- NISA成長投資枠でも毎月積立を登録可能
- 累計買付額（実元本）を入力可能
- 評価損益を「現在評価額 − 累計買付額」で計算
- 累計買付額が未入力の旧データは、開始日×毎月額の推定元本を使い「元本は推定」と表示
- 旧データと保存キーはそのまま維持


## 8.0 Beta 第4弾 NISA利用枠版

- 投資ダッシュボードの4つの集計カード直下に、当年のNISA利用枠を追加
- 本人・夫それぞれについて、つみたて投資枠（年120万円）と成長投資枠（年240万円）を別表示
- 今年の買付額、残り枠、使用率を表示
- 家族合計タブでは本人・夫を分けて表示（枠は個人ごとのため）
- 評価額や累計元本から自動推定せず、証券会社の当年買付額を手入力する方式


## 8.0 Beta 第5弾 NISA年末予測版

- 現在入力しているNISA利用額と、登録済みの毎月積立額から年末の利用見込みを表示
- つみたて投資枠・成長投資枠を別々に予測
- 年末に残る見込み額、上限超過見込み、残り枠を使い切る月額の単純目安を表示
- 本人・夫・家族合計に対応
- 予測は来月から12月までの積立を加算し、現在月の二重計上を避ける方式
- 既存データと保存キーはそのまま維持


## 8.0 Beta 第6弾 NISA自動集計版

- NISA買付履歴を日付・商品・枠・金額・証券会社ごとに登録
- 開始時点の利用額に、今年の買付履歴を自動加算
- 利用額・残り枠・年末予測へ即時反映
- 買付履歴の編集・削除に対応
- NISA商品カードの「買付を記録」から商品名と証券会社を自動入力
- 本人・夫・家族合計に対応
- 第5弾までの入力済み利用額とバックアップをそのまま維持


## 8.0 Beta 第7弾 データ点検版

- 同一内容の保有資産・積立・NISA買付履歴の重複候補を検出
- 暫定調整として残っている資産を明示
- 取得単価と現在価格の極端な差から桁入力の候補を表示
- 累計買付額が未入力で元本が推定計算の積立を表示
- 候補から保有資産・積立の確認・編集へ移動
- 自動削除や自動修正は行わず、既存データをそのまま維持


## 8.0 Beta 第8弾 同一登録確認版

- 同じ内容の保有資産を、直ちに「重複」と断定しない表示へ変更
- 100株ずつ2回購入した場合などを「別々の買付で正しい」と確認可能
- 確認済みの組み合わせは、以後の点検警告から除外
- 積立登録・NISA買付履歴の同一内容にも同じ確認方式を適用
- 確認済み状態を一括リセットできるボタンを追加
- 誤登録の場合は従来どおり一覧から不要な登録だけを削除
- 既存データ・配当金・保存キーはそのまま維持


## 8.0 Beta 第9弾 配当金管理Pro

- 年間配当予定・今年の受取済み・残り予定・次回予定をまとめて表示
- 月別配当カレンダーと棒グラフを表示
- 受取日・銘柄・金額・メモを記録し、編集・削除可能
- 本人・夫・家族合計の切り替えに対応
- 今月または次回の配当予定を通知カードで表示
- 配当利回りランキングへワンタップで移動
- 第8弾までのデータと保存キーをそのまま維持


## 8.0 Beta 第11弾 資産・配当推移版

- 金融資産・投資評価額・年間配当予想を毎月スナップショット保存
- 直近12か月の金融資産／投資評価額を2本の線で比較
- 年間配当予想の推移グラフ
- 前月比と過去最高金融資産を表示
- 「今月を記録」で手動更新でき、従来の自動保存も継続
- 過去データ・配当履歴・NISA履歴をそのまま維持


## 8.0 Beta 第11弾 目標ダッシュボード版

- ホームに住宅ローン・教育資金・目的別積立・総資産目標の進捗バーを追加
- 住宅ローンの現在残高から完済までの残高推移をグラフ表示
- 借入時金額を入力し、返済済み金額・進捗率・残り残高を表示
- 現在残高・金利・毎月返済・ボーナス返済から完済時期を概算
- 既存の資産・配当・NISA・バックアップデータはそのまま引き継ぎ


## 8.0 Beta 第12弾 住宅ローン進捗修正版

- 借入時金額と現在残高から返済済み金額・進捗率を確実に計算
- 入力中も進捗バーを即時プレビュー
- 保存時に端末内へ同期的に書き込み、画面へ即時反映
- 旧版の借入時金額フィールド名も自動移行
- サービスワーカーのキャッシュを更新


## 8.0 Beta 第13弾 人生ロードマップ版
- 家族の目標を平均進捗・達成に近い目標・次の期限・要確認件数で要約
- 期限と積立ペースから、今いちばん意識したい目標を自動表示
- 教育・車・旅行・住宅ローンなどを時系列で並べた家族予定タイムライン
- 第12弾までの住宅ローン進捗、投資、配当、NISA、履歴データを維持


## 8.0 Beta 第14弾 ホームダッシュボード版

- ホーム上部に家族のお金の進捗を集約
- 住宅ローン・教育資金・目的別積立・金融資産・NISAを横断表示
- 平均進捗リングと「あといくら」を同時表示
- ライフ・投資画面へすぐ移動できるボタンを追加
- 既存データ、配当、NISA、住宅ローン修正をそのまま維持


## 8.0 Beta 第15弾 ライフプランタイムライン版

- ライフイベント・積立目標・住宅ローンを1本の未来年表に統合
- 次の節目、10年後の金融資産見込み、10年後のローン残高を表示
- 年ごとに金融資産見込みとローン残高を並べて比較
- 金融資産見込みは運用益を含めない単純積立として明示
- 第14弾までのホームダッシュボード、投資、配当、NISA、住宅ローン修正を維持


## 8.0 Beta 第16弾 未来シミュレーション版
- 想定利回り・追加積立・表示期間を変更して将来資産を試算
- 金融資産と住宅ローン残高を同じグラフで比較
- 10年後・期間終了時・資産目標到達年を表示
- 3人分の教育資金達成率と残額を表示
- 登録済み予定支出を概算へ反映
