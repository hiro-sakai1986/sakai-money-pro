# サカイ家 MONEY Pro 8.0 Alpha

7.0 第三弾Dの全データを引き継ぎながら、8.0用の新しい画面デザインと保存領域へ移行した最初の開発版です。

## 8.0 Alphaで変更したこと
- iPhoneアプリ風の新しいホームデザイン
- 8.0専用ストレージキー（7.0 第三弾Dから自動移行）
- ライフプランタブの名称整理
- 日付・端末内保存ステータス表示
- PWAキャッシュ更新

既存の家計・投資・住宅ローン・教育資金・目的別積立・ライフイベント機能はそのまま利用できます。


## 8.0 Alpha データ復旧修正版

旧バージョンで実際に使われていた保存名も検索し、8.0が先に空データを保存した後でも、
同じブラウザー内に残っている旧データを自動で引き継ぐように修正しました。


## 8.0 Beta 家計画面

- 月別の収入・支出・収支・貯蓄率を表示
- 月ごとの支出予算と予算オーバー判定
- よく使うカテゴリから簡単入力
- 家計記録の編集・削除
- 6か月の収入・支出グラフ
- 支出カテゴリ別の内訳と割合
- 8.0 Alphaの保存データをそのまま引き継ぐため、保存キーは維持


## 8.0 Beta 第2弾 投資画面

- 本人・夫・家族合計の投資ダッシュボード
- 投資評価額・元本・損益率・年間配当・毎月積立を一画面に集約
- 資産種類別と口座別の構成比
- 集中度、価格未入力、積立額、配当月未入力の端末内チェック
- 保有資産・積立・ランキング・配当をタブで切替
- 保有商品の構成比バー、NISA口座チップ、入力不足表示
- 既存の8.0 Betaデータをそのまま維持（保存キー変更なし）


## 自動保存強化修正版

- 保存名を今後の更新でも固定
- 通常保存に加えて予備保存（IndexedDB）を追加
- アプリを閉じる・バックグラウンドへ移す直前にも保存
- 通常保存が消えた場合は予備保存から自動復旧
- GitHub Pages更新後も同じ保存領域を継続使用


## 配当カレンダー修正版

- 「本人」「ヒロ」「妻」「自分」「私」を本人名義として統一
- 「夫」「旦那」「主人」を夫名義として統一
- 旧データの名義表記が違っていても配当カレンダーに表示
- 配当月は `6,12` のほか、`6月・12月`、`6／12`、全角数字にも対応
- 同じ月が重複入力されても一度だけ計算
- 保存領域と既存データはそのまま継続


## 8.0 Beta 第3弾 投資枠整理版
- 「買い方（毎月積立／一括購入）」と「口座区分（NISAつみたて／NISA成長／特定など）」を分離
- NISA成長投資枠でも毎月積立を登録可能
- 累計買付額（実元本）を入力可能
- 評価損益を「現在評価額 − 累計買付額」で計算
- 累計買付額が未入力の旧データは、開始日×毎月額の推定元本を使い「元本は推定」と表示
- 旧データと保存キーはそのまま維持


## 8.0 Beta 第4弾 NISA利用枠版

- 投資ダッシュボードの4つの集計カード直下に、当年のNISA利用枠を追加
- 本人・夫それぞれについて、つみたて投資枠（年120万円）と成長投資枠（年240万円）を別表示
- 今年の買付額、残り枠、使用率を表示
- 家族合計タブでは本人・夫を分けて表示（枠は個人ごとのため）
- 評価額や累計元本から自動推定せず、証券会社の当年買付額を手入力する方式


## 8.0 Beta 第5弾 NISA年末予測版

- 現在入力しているNISA利用額と、登録済みの毎月積立額から年末の利用見込みを表示
- つみたて投資枠・成長投資枠を別々に予測
- 年末に残る見込み額、上限超過見込み、残り枠を使い切る月額の単純目安を表示
- 本人・夫・家族合計に対応
- 予測は来月から12月までの積立を加算し、現在月の二重計上を避ける方式
- 既存データと保存キーはそのまま維持


## 8.0 Beta 第6弾 NISA自動集計版

- NISA買付履歴を日付・商品・枠・金額・証券会社ごとに登録
- 開始時点の利用額に、今年の買付履歴を自動加算
- 利用額・残り枠・年末予測へ即時反映
- 買付履歴の編集・削除に対応
- NISA商品カードの「買付を記録」から商品名と証券会社を自動入力
- 本人・夫・家族合計に対応
- 第5弾までの入力済み利用額とバックアップをそのまま維持
